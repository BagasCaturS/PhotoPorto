# Session Handoff — Photography Portfolio
**Tanggal:** 26 Juli 2026 (Sesi 2)

## 1. Ringkasan Project
Portfolio website fotografi dengan Next.js 16.2.12 (Turbopack), Tailwind CSS v4, TypeScript, Supabase (auth + storage + database). Admin dapat mengelola foto galeri (metadata, seleksi, hero) dan menulis jurnal. Monochrome theme (#18181B/#FAFAFA) + Blue accent (#2563EB), Archivo + Space Grotesk. Terdeploy di Vercel, repo di `github.com/BagasCaturS/PhotoPorto`.

## 3. Keputusan Penting & Alasannya
- **Batch upload per-file form**: Setiap file di batch punya row sendiri (title, desc, category) — bukan common field untuk semua. User bisa edit masing-masing sebelum upload.
- **is_hero via partial unique index**: `CREATE UNIQUE INDEX ... WHERE is_hero = true` — cuma satu foto bisa jadi hero. Unset dulu yang lama, set yang baru (2 sequential PUT requests).
- **Hero fetch parallel dengan gallery**: `Promise.all` dua query — gallery (selected photos) + hero (is_hero) — biar gak ngeblock render.
- **Proxy rename**: Next.js 16 deprecated `middleware.ts`, rename ke `proxy.ts`. Fungsi rename dari `middleware` ke `proxy`.

## 7. Catatan/Gotcha
- `.env.local` butuh `SUPABASE_SERVICE_ROLE_KEY` untuk upload script via CLI. Tapi upload via admin panel pake anon key (RLS), jadi script gak wajib — bisa upload manual lewat browser.
- Kalau login redirect loop, cek Console browser — mungkin profile row belum ada. SQL fix: `INSERT INTO profiles (id, email, role) SELECT id, email, 'admin' FROM auth.users WHERE id NOT IN (SELECT id FROM profiles) LIMIT 1;`
- Policy "Admins can read all" di profiles SUDAH di-drop. Cuma ada "Users can read own profile".
- Journal cover upload ke `photos` bucket → `covers/` path.
- Hero unique index memastikan cuma satu foto jadi hero. Tapi kode client unset dulu yang lama (sequential), jadi aman.
- Build lokal pake `npm run build`. Run dev pake `npm run dev`.
